Project Name: CodeClash

Build a production-grade real-time competitive coding battle platform inspired by Codeforces, Chess.com matchmaking and PUBG battle royale.

IMPORTANT

I am starting from scratch.

Design and implement the complete platform using best engineering practices.

The goal is not another coding practice website.

The goal is to create the most engaging multiplayer coding battle experience possible.

Tech Stack

* Next.js
* Node.js
* Express
* MongoDB/Postres SQL 17
* Socket.IO

CORE CONCEPT

Codeforces is the source of truth.

Do NOT build a custom judge.

Do NOT maintain hidden testcases.

Codeforces handles:

* submissions
* verdicts
* hidden testcases
* judging

CodeClash handles:

* matchmaking
* battle rooms
* rankings
* spectators
* leaderboards
* battle experience

MATCH START RULE

Timer must NEVER start when room is created.

Timer starts ONLY when:

* all required players joined
* players are ready
* host starts battle

FAIR MATCH SYSTEM

Extremely important.

Every player in a battle must receive the SAME problem.

Examples:

1v1:

* same problem

Deathmatch:

* same problem

Multiplayer:

* same problem

No player should ever receive an easier or harder problem than another player in the same match.
